# HireNest – Online Job Portal

HireNest is a web-based job portal developed using PHP and MySQL.

## Features

- Applicant registration and login
- Company registration and login
- Admin dashboard
- Job posting and management
- Job search and filtering
- Online job applications
- Resume upload and download
- Application status tracking
- Secure authentication and role-based access

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap (if used)

## Local Setup

1. Install XAMPP.
2. Copy the project into `htdocs`.
3. Start Apache and MySQL.
4. Create a database named `hirenest_db`.
5. Import the project's SQL database structure.
6. Configure the database connection in `config/database.php`.
7. Open the project through localhost.
